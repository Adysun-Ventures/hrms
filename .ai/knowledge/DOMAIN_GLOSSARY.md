# Domain Glossary: Indian Banking & Financial Systems

This glossary defines standard financial, banking, and data terms used throughout the Statement Builder codebase.

---

## 1. Banking Identifiers
- **CRN (Customer Relationship Number)**: An 8-to-10 digit customer identification number used primarily by Kotak Mahindra Bank (e.g. `98234135`). Displayed in customer info.
- **Cust ID (Customer ID)**: Unique customer identifier used by HDFC Bank and others (e.g. `114715446`).
- **IFSC (Indian Financial System Code)**: An 11-character alphanumeric code identifying a specific bank branch for NEFT/RTGS/IMPS (e.g., `KKBK0001767`, `HDFC0000794`).
  - First 4 letters: Bank code (`KKBK` = Kotak, `HDFC` = HDFC).
  - 5th character: Always `0`.
  - Last 6 characters: Branch identifier.
- **MICR (Magnetic Ink Character Recognition)**: A 9-digit numeric code printed on cheques to identify the branch for cheque clearing (e.g. `411485022`, `411240018`).
  - First 3 digits: City code.
  - Middle 3 digits: Bank code.
  - Last 3 digits: Branch code.
- **GSTN / GSTIN**: 15-digit Goods and Services Tax Identification Number for bank branches (e.g. `27AAACH2702H1Z0` where `27` is Maharashtra state code).

---

## 2. Transfer Types & Transaction Codes
- **UPI (Unified Payments Interface)**: Instant real-time payment system via VPA (Virtual Payment Address).
  - *RRN (Retrieval Reference Number)*: 12-digit numeric identifier generated by UPI switch (e.g. `0000386912320314`).
  - Standard Kotak Narration: `UPI/<Beneficiary>/<Bank>/<RRN>/Payment from`
  - Standard HDFC Narration: `UPI-<Beneficiary>-<VPA>-<RRN>-PAYMENT FROM PHONE`
- **NEFT (National Electronic Funds Transfer)**: Nationwide payment system used for batch fund transfers, especially monthly corporate salaries.
  - Standard Narration: `NEFT CR-<IFSC>-<Company>-<Beneficiary>-<UTR>-SALARY`
- **IMPS (Immediate Payment Service)**: Real-time 24x7 interbank electronic fund transfer service.
- **ACH / NACH (National Automated Clearing House)**: Used for recurring electronic mandates like EMI loans and insurance (e.g. `ACH D- HERO FINCORP LTD-66111801`, `ACH D- PAYU FINANCE`).
- **ATM Cash Withdrawal**: Cash dispenses from automated teller machines (e.g. `ATM CASH WDL - KKBK BANER`).

---

## 3. Financial Mechanics
- **Paise**: Smallest unit of Indian currency (1 INR = 100 Paise). Stored as integers throughout computation to eliminate IEEE-754 floating point inaccuracies.
- **Value Date**: The effective date on which the transaction financial impact is recognized (may differ from transaction booking date due to clearing cycles).
- **Opening Balance**: Account balance at the beginning of the statement period.
- **Closing Balance**: Calculated final balance (`Opening + Total Credits - Total Debits`).
- **Earmarked / Hold Funds**: Balance reserved for uncleared cheques or merchant holds.
